# Flow Board

A drag-and-drop kanban board for tracking work.

## Features

- Three columns with drag and drop between them
- Double-click a card to edit it in place
- Low, medium and high priority labels
- Saved to your browser

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.

## Files

```
index.html   markup
styles.css   styling
script.js    behaviour
```

## Tech

Plain HTML, CSS and JavaScript.
